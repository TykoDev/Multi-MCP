# Contributing

Bug reports, documentation fixes and well-scoped features are welcome. Open an issue with the
[bug report](.github/ISSUE_TEMPLATE/bug_report.md) or [feature request](.github/ISSUE_TEMPLATE/feature_request.md)
template first.

Setting up, the rules a change follows, the test tiers and the pull-request workflow are in
[docs/development.md](docs/development.md); the project's non-negotiables are in [AGENTS.md](AGENTS.md).

[Code of Conduct](CONDUCT.md) · report vulnerabilities privately per [SECURITY.md](SECURITY.md) · contributions are
licensed under the [MIT License](LICENSE).
